# Collapse tree item modules into one

Item.tsx (696 lines) has 5 near-copies (Dir, File, Submodule, SymlinkDir, SymlinkFile) each re-deriving hover, expand, prefetch, preview, row markup. Drift: commit cell gets path/""/virtualPath by kind; collapse-dirs only in Dir; hover prefetches path while expand renders leafPath.

## Design

Single tree item module taking a resolved entry + level; per-kind variation (icon, title, expandable, previewable) as data. Symlink resolution before it.

## Acceptance Criteria

One item module; behaviour identical across kinds; one test file covering all kinds.
