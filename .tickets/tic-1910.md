# Repo tree module over GitHub GraphQL

Entry normalisation lives in repoContentsQueryConfig select, which useDirChainQuery bypasses (exports getTypeFromMode as workaround). Submodule repo encoded into html_url then parsed back in Contents. GraphQL strings across 4 files. Item.test.tsx mocks REST endpoints code no longer calls.

## Design

Repo tree module returns normalised TreeEntry union from queryFn: dir | file | submodule{repository} | symlink{target}. Hooks become thin.

## Acceptance Criteria

No html_url round-trip for submodules; no select bypass; tests mock GraphQL seam only.
